#PalindromeCheckerApp
Overview

This is a console-based Java application that establishes the main class and application startup flow.
It displays a welcome message and version information and confirms successful system initialization.
No palindrome checking logic is implemented in this version.

Project File

PalindromeCheckerApp.java

Main class: PalindromeCheckerApp

Requirements

Java Development Kit (JDK) 8 or higher

Command line or terminal

How to Compile

Open a terminal in the project directory.

Run the following command:

javac PalindromeCheckerApp.java
How to Run

After successful compilation, run:

java PalindromeCheckerApp
Expected Output
Welcome to the Palindrome Checker Management System
Version : 1.0
System initialized successfully.
Purpose of This Version

Establish a clear startup flow

Verify Java environment setup

Prepare the structure for future palindrome checking implementation
