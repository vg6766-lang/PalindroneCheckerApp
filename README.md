# PalindroneCheckerApp


1. Overview

   * Console-based Java application.
   * Establishes the main class and application startup flow.
   * Displays a welcome message and version information.
   * Confirms successful system initialization.
   * No palindrome checking logic is implemented in this version.

2. Project File

   * PalindromeCheckerApp.java
   * Main class:PalindromeCheckerApp

3. Requirements

   * Install Java Development Kit (JDK 8 or higher).
   * Use a command line or terminal.

4. How to Compile

   * Open terminal in the project directory.
   * Run the following command:
     javac PalindromeCheckerApp.java

5. How to Run

   * After successful compilation, run:
     java PalindromeCheckerApp

6. Expected Output

   * Welcome to the Palindrome Checker Management System
   * Version : 1.0
   * System initialized successfully.

7. Purpose of This Version

   * Establish a clear startup flow.
   * Verify Java environment setup.
   * Prepare structure for future palindrome checking implementation.
